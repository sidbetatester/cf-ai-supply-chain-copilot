---
description: Format and content rules for a leadership status report (RAG, milestones, risks, asks)
---

Write the status report in this structure, using only data from the project state:

1. **Headline**: overall RAG (Red if any gating delivery lands after its milestone, Amber if slack is under 5 days, otherwise Green) and one sentence on why.
2. **Milestones**: table of id, name, due date, status.
3. **Critical path**: the gating POs with the least slack, with landed date vs. milestone due date.
4. **Top risks and issues**: open RAID items with high severity first, each with owner.
5. **Decisions made**: recent Decision items.
6. **Asks**: concrete decisions or help needed from leadership, each with a date.

Keep it under 250 words. No speculation beyond the data.
